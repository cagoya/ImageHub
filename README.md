# ImageHub

## 简介

### 功能

搭建了一个存储图片的Web应用，实现的功能如下：

1. 用户注册登录和修改个人信息
2. 支持用户登录后上传图片，会自动从图片中提取拍摄时间、地点和像素等信息
3. 支持用户自定义标签和AI识图添加标签
4. 支持在浏览器中对图片进行编辑
5. 显示图片缩略图，支持图片轮播
6. 支持按照多种条件搜索，支持AI对话搜索

### 技术栈

- 前端：Vue(ts) + Element Plus
- 后端：gin(golang) + gorm
- 数据库：MySQL + Redis
- 鉴权：JWT
